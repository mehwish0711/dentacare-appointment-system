Dentacare - Dental Clinic Website

Dentacare is a modern and responsive dental clinic website developed using PHP, MySQL, HTML, CSS, and JavaScript. This project is designed to provide a complete online presence for dental clinics, including appointment booking, service display, and patient interaction.

---

 Features

-  Modern and responsive UI design
-  Online appointment booking system (AJAX based)
-  Patient data stored in MySQL database
-  Contact and inquiry form
-  Patient reviews section with slider
   Mobile-friendly design
-  Secure form handling (basic validation)

---

 Technologies Used

- HTML5
- CSS3
- JavaScript (jQuery & AJAX)
- PHP (Core PHP)
- MySQL Database
